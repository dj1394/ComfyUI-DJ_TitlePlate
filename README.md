# ComfyUI-DJ_TitlePlate（大江 标题 · 画布浮动文字标签）

> **版本** `260922-090052` · **作者** 大江 · **平台** ComfyUI（Vue 版前端）
> **依赖** 无特殊依赖 · **许可** 未声明

## 一、功能概述

在 ComfyUI 画布任意位置放置浮动文字标签，给工作流画面加标题、字幕、水印。文字由 canvas 直接渲染（不占节点 UI），支持多行、旋转、背景色、圆角；单击调字号、双击原地改字，操作像贴便利贴一样直接。

## 二、功能说明

### 2.1 创建节点

| 功能 | 触发方式 | 说明 / 默认行为 |
|---|---|---|
| 新建标签 | `Ctrl+K` 搜「大江 标题」，或右键菜单「大江」分类 | 后端是影子节点（无输入输出、执行不产生结果），前端虚拟类接管渲染；节点不可折叠、不可拖角缩放，尺寸由文字自动撑开 |

### 2.2 编辑文字

| 功能 | 触发方式 | 说明 / 默认行为 |
|---|---|---|
| 原地编辑 | **双击**标签 | 透明 textarea 覆盖在文字上（视觉仍由画布渲染），输入实时写回、尺寸随之变化 |
| 保存 | `Enter` 或点标签外空白 | 写入节点并关闭编辑器 |
| 取消 | `Esc` | 丢弃改动，关闭编辑器 |
| 换行 | `Shift+Enter` | 支持多行；画布文字垂直居中 |

编辑态样式：虚线框 `1px dashed rgba(0,255,0,0.4)`、canvas 层 2% 淡绿底垫在文字下面；textarea 用 `all:unset` 重置浏览器默认边框，宽度按 `measureText` 算出的最宽行 + padding 贴合内容。

### 2.3 字号横条

| 功能 | 触发方式 | 说明 / 默认行为 |
|---|---|---|
| 弹出横条 | **单击**标签（延迟 250ms，避免双击时闪现） | 横条锚定在标签上方，跟随缩放/平移；编辑中不弹 |
| 拖动改字号 | 横条轨道左右拖 | 每 2 屏幕像素 = 1 号字；滑块填充按对数映射（小字号更灵敏），视觉上限 96px |
| 精确输入 | 右侧数字框输值 + `Enter` | 字号范围 `12`–`300` px，默认 `32` px |
| 关闭 | 点标签外 / `Esc` / 切走窗口 | — |

### 2.4 样式属性（右键菜单「属性」）

| 属性 | 选项 / 取值 | 默认值 |
|---|---|---|
| fontSize | 12–300 px | 32 |
| fontFamily | 字体族名 | Arial |
| fontColor | 十六进制（7-8 位可带透明度） | #ffffff |
| textAlign | left / center / right | left |
| backgroundColor | 十六进制 / transparent | transparent |
| padding | px | 0 |
| borderRadius | px | 0 |
| angle | 旋转角度（度） | 0 |
| showBorder | true / false | false（默认不显示虚框） |

### 2.5 钉住

| 功能 | 触发方式 | 说明 / 默认行为 |
|---|---|---|
| 钉住 / 取消 | 右键菜单「钉住」 | 钉住后点击穿透：单击标签会命中它下面的节点（双击仍可编辑） |

### 2.6 帮助

| 功能 | 触发方式 | 说明 / 默认行为 |
|---|---|---|
| 帮助对话框 | 右键菜单「🛟 帮助」 | 弹出操作说明，背景虚化；点遮罩或「关闭」退出 |

3. **验证 + 提醒重启**：检查代码能读通后告诉你装完，然后提醒你**重启 ComfyUI** 生效。

### 安装铁律（本地插件专用，不可违反）

- **本地手搓插件一律用 `link:` / junction 指向源码目录，绝不打包成 `.tgz`、绝不用 `file:xxx.tgz`。**
- 为什么：插件就放在源码目录里，改完代码刷新/重启就生效；junction 在这里只干一件事——在安装位置放一个"快捷方式"指向源码目录。一旦打成 tgz 包，每次安装都从旧包解包覆盖，你改好的代码会被反复还原成旧版本；本地插件不上传、不分发，打 tgz 包纯属自找麻烦。

## 四、注意事项 / 已知边界

1. **灰虚框与黑边框的根因**（本次修复的核心）：
   - 非编辑态的灰色虚线框是 **LiteGraph 自己在 canvas 里画的**（`drawNode` → `drawNodeShape`），不是 DOM——CSS、内联样式全部无效。最终方案是劫持 `LGraphCanvas.prototype.drawNode`，对标题节点完全跳过原版绘制，直接调自己的 `node.draw(ctx)`。
   - 编辑态的黑色边框是 **textarea 的浏览器默认边框**：常规 `border:none; outline:none` 去不掉，必须 `all:unset` 才能彻底重置。排查时靠「颜色标记法」（逐个改醒目色）+「切窗口测试法」（focus 变化让不同层级露出）定位到它。
2. **Vue 版前端下**：LiteGraph 的 `onDblClick` 不触发，双击走 Vue DOM 层捕获绑定（`attachVueDblClick`）；节点 wrapper 在编辑时打 `data-dj-title-editing="true"` 标记供 CSS 消除边框。
3. **滚动**：编辑器容器空白处滚轮会转发给画布（缩放），textarea 内滚动正常。
4. **焦点保护**：焦点被抢走会自动拉回；跑到别的节点 DOM 上则保存关闭。
